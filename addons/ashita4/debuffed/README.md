# debuffed (OverlordsXI)

Ashita v4 target buff/debuff panel with native custom status icons.

- Live data: silent `[OXMOB]|<mobServerId>|<part>/<parts>|<effectId>:<iconId>:<power>:<sub>:<isDebuff>:<remSec>,...`
  `0x017` packets from the server module `overlords_mob_status_sync.lua` (blocked from chat).
- Fallback: `0x028`/`0x029` parsing (estimated `~Ns` / `+Ns` timers) until live data arrives.
- Icons: custom effects (`789`, `815+`) use cached `assets/status_icons/<iconId>.png`; vanilla `1..639` use the client's `ROM/119/57.DAT` icons.
- `status_catalog.lua` and `assets/status_icons/` are generated by `tools/build_custom_status_dats.py`. Do not edit by hand.

Commands: `/debuffed [toggle|show|hide|lock|unlock|size <12-48>|buffs|reset]`

Load with `/addon load debuffed`.
